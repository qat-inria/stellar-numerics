    max_trace_distance_precision(protocol, nb_copies, to_profile, from_profile=None, from_rank=None)

    Bound conversion error using stellar profiles and a protocol.

    Parameters:

    Name Type Description Default
    protocol Protocol

    Deterministic (standard) or postselected conversion protocol.

    		 required
    nb_copies int

    Number of input copies used in the conversion.

    		 required
    to_profile StellarProfile

    Profile of the pure target state.

    		 required
    from_profile StellarProfile or None

    Profile of the input state. Required for the standard protocol and ignored for the postselected protocol.

    		 None
    from_rank int or None

    Input stellar rank. Required for the postselected protocol.

    		 None

    Returns:

    Type Description
    float

    Maximum trace-distance precision bound for the selected protocol.

    Raises:

    Type Description
    ValueError

    If the required input profile or rank is missing.
    TypeError

    If the target profile represents a mixed state.

    Warns:

    Type Description
    UserWarning

    If an input profile is supplied for the postselected protocol.

    max_trace_distance_precision_pure_pure_std(from_profile, to_profile, nb_copies)

    Compute the deterministic conversion bound for pure states.

    Parameters:

    Name Type Description Default
    from_profile StellarProfile

    Stellar profile of the pure input state.

    		 required
    to_profile StellarProfile

    Stellar profile of the pure target state.

    		 required
    nb_copies int

    Number of input copies used in the conversion.

    		 required

    Returns:

    Type Description
    float

    Maximum trace-distance bound evaluated over the ranks available in both profiles.
    Notes

    Implements Eq. (36) of [HGFFC25]. The profiles are expected to contain contiguous ranks from zero through their maximum rank.

    max_trace_distance_precision_mixed_pure_std(from_profile, to_profile, nb_copies)

    nb_copies int

    Returns:

    max_trace_distance_precision_pure_pure_post(to_profile, from_rank, nb_copies)

    Compute the postselected conversion bound for pure states.

    Parameters:

    Name Type Description Default
    to_profile StellarProfile

    Stellar profile of the pure target state.

    		 required
    from_rank int

    Stellar rank of the input state.

    		 required
    nb_copies int

    Number of input copies used in the conversion.

    		 required

    Returns:

    Type Description
    float

    Trace-distance bound evaluated at target rank nb_copies * from_rank.
    Notes

    get_statevector(cutoff=None)

    returns the statevector of a GaussianState object. From Chabaud draft Eq. [F15]

    Parameters:

    Name Type Description Default
    cutoff int

    single-mode Fock space cutoff i.e. the highest Fock number reached

    		 None

    Returns:

    Name Type Description
    res Statevector

    output statevector as a :class:stellar.cvstates.Statevector object.

    Raises:

    Type Description
    TypeError

    if the parameter cutoffis not an integer.
    TypeError

    if the parameter cutoff is not a strictly positive integer.
    Notes

    Formula is ill-defined for zero squeezing. Use a very small squeezing amplitude or :class:stellar.cvstates.CoherentState instead. Need to shift convention with respect to ours : xi-> xi* so theta -> - theta wrt paper

    Parameters

    params

    GaussianParameters dataclass

    Parameters describing a single-mode Gaussian state or operation.

    Parameters:

    Name Type Description Default
    x float

    Real and imaginary parts of the displacement, respectively.

    		 required
    y float

    Real and imaginary parts of the displacement, respectively.

    		 required
    r float

    Non-negative squeezing magnitude.

    		 required
    theta float

    Squeezing phase in radians.

    		 required
    Notes

    Instances are immutable and hashable.

    displacement property

    complex: Displacement amplitude x + 1j*y.

    squeezing property

    complex: Complex squeezing parameter r * exp(1j*theta).

    OptimisationParameters dataclass

    Configuration for computing stellar fidelities and profiles.

    Parameters:

    Name Type Description Default
    method Method

    Representation used for the optimization objective: Fock-basis or Gaussian-state evaluation.

    		 required
    target_cutoff int or None

    Highest Fock number used to represent the target in the Fock basis. Required when method is :attr:Method.fock; ignored for :attr:Method.gaussian.

    		 None
    niter int

    Number of basin-hopping iterations.

    		 250
    x0 tuple of float

    Initial values for displacement components, squeezing magnitude, and squeezing phase.

    		 (0.1, 0.1, 0.1, 0.1)
    seed int or None

    Random seed passed to the optimizer.

    		 None

    Raises:

    Type Description
    ValueError

    If Fock-basis optimization is selected without target_cutoff.

    Warns:

    Type Description
    UserWarning

    If target_cutoff is supplied for Gaussian-state optimization.
